# Portfolio Website

A modern, responsive, and visually engaging personal portfolio website designed and developed from scratch using **HTML5** and **CSS3**. This project showcases my skills, learning journey, and passion for front-end web development through a clean user interface, structured layouts, and responsive design principles.

The website features a professionally designed navigation bar, an introduction section, a skills showcase with animated progress bars, modern card layouts, hover effects, gradients, shadows, and responsive components built using **CSS Flexbox** and **CSS Grid**. Every section has been carefully crafted with a focus on readability, user experience, and clean visual aesthetics.

This portfolio is more than just a showcase—it's a record of my growth as a developer. As I continue learning new technologies such as **JavaScript**, **React**, and backend development, I will continuously improve and expand this project by adding interactive features, real-world projects, animations, dark/light mode, and additional sections.

### Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* Responsive Web Design

### Goals

* Build a professional online presence.
* Apply modern web design principles.
* Practice writing clean, organized, and maintainable code.
* Continuously improve the project as I learn new technologies.

This repository represents my commitment to becoming a skilled full-stack web developer, with every update reflecting new concepts, better design decisions, and continuous improvement.
